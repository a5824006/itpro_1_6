1. 用語の説明 18点

次の用語について、日本語訳または意味と、ITPro2での役割を1-2文で説明しなさい。

  1. HTML
  2. element
  3. attribute
  4. structural markup
  5. CSS rule
  6. selector
  7. box model
  8. Ruby block
  9. string interpolation
  10. CGI
  11. ERB
  12. query part
  13. form
  14. database
  15. primary key
  16. ORM
  17. Active Record
  18. convention over configuration
  1. HTML: Webページの構造と意味をマークアップする言語。
  2. element: `<p>...</p>` のように、開始タグ・内容・終了タグなどで表される構成単位。
  3. attribute: 開始タグ内で要素に追加情報を与えるもの。例: `id`, `class`, `lang`, `href`。
  4. structural markup: 見た目ではなく、段落・見出し・強調など文書上の役割を表すマークアップ。
  5. CSS rule: セレクタと宣言ブロックからなるスタイル指定。例: `p { color: navy; }`。
  6. selector: CSSを適用する対象を選ぶ部分。例: `p`, `.warning`, `#main`, `p code`。
  7. box model: 内容、padding、border、marginから要素の箱を考えるモデル。
  8. Ruby block: メソッド呼び出しに渡す処理のまとまり。`do ... end` や `{ ... }` で書く。
  9. string interpolation: ダブルクォート文字列中の `#{...}` で式の値を埋め込む機能。
  10. CGI: Webサーバが外部プログラムを呼び出し、標準出力からWebページを返す仕組み。
  11. ERB: HTMLの中にRubyコードを埋め込むテンプレート。`.html.erb` で使う。
  12. query part: URIの `?` より後ろ。`name=value&name2=value2` の形でパラメータを送る。
  13. form: ユーザ入力を送るHTML要素。`input`, `label`, `submit` などを含む。
  14. database: 多数のデータを構造化して保存・検索する仕組み。
  15. primary key: 表の各行を一意に識別する列。典型例は `id`。
  16. ORM: オブジェクト指向言語のオブジェクトと、リレーショナルDBの表・行を対応させる仕組み。
  17. Active Record: Railsで使われるORM。表の行をRubyオブジェクトとして扱える。
  18. convention over configuration: 規約に従えば細かい設定を書かずに動くというRailsの考え方。

2. HTML構造を書く 12点

「RubyとWebアプリ」という題名のWebページを作る。次の条件を満たすHTMLを書きなさい。

3. CSSを読む・書く 16点

次のCSSについて、各セレクタの種類と、指定される内容を説明しなさい。

main p code {
  background-color: #f6f6f6;
  padding: 0.1em 0.3em;
}

.warning {
  color: red;
  border: 2px solid orange;

さらに、`#summary` の margin の上・右・下・左を答えなさい。

  • `main p code`: 子孫結合子。`main` の中の `p` の中にある `code` 要素に適用。背景色と内側余白を指定。

4. Rubyの構文 18点

次のC風の関数と同じ働きをするRubyのメソッドを書きなさい。0から100までの点数 `mark` と実数 `exponent` を受け取り、変換後の点数を整数で返す。

int convert_mark(int mark, double exponent)
{
    return round(pow(mark, exponent) * (100.0 / pow(100, exponent)));
}

その後、0, 10, 20, ..., 100 について、`n points -> converted points` の形で出力するRubyコードも書きなさい。

def convert_mark(mark, exponent)
  (mark**exponent * (100.0 / 100**exponent)).round
end

(0..100).step(10).each do |n|
  puts "#{n} points -> #{convert_mark(n, 0.5)} points"
end

`**` は累乗、`.round` は四捨五入、`#{...}` は文字列補完です。`(0..100)` は両端を含むRangeです。

A7. CSSの衝突と継承 14点

次のHTMLとCSSについて、`Hello` の色、背景色、文字サイズがどうなるか説明しなさい。

<body>
  <main id="content">
    <p class="warning"><code>Hello</code></p>
  </main>
</body>
body { color: black; font-size: 16px; }
p { color: blue; background-color: white; }
.warning { color: red; }
#content code { background-color: #eee; }
code { font-size: 90%; }
  • 色は `red`。`code` 自身には `color` がないため親の `p.warning` から継承され、`.warning` が `p` より優先される。

  • 文字サイズは `16px` の90%、つまり約 `14.4px`。`code { font-size: 90%; }` が親のサイズに対して効く。

B3. CからRubyへ 16点

次のCの関数と同じ働きをするRubyのメソッドを書きなさい。できるだけRubyらしく書くこと。

int letter_mark(int mark)
{
    if (mark >= 90) return 5;
    if (mark >= 80) return 4;
    if (mark >= 70) return 3;
    if (mark >= 60) return 2;
    return 1;
}
def letter_mark(mark)
  if mark >= 90
    5
  elsif mark >= 80
    4
  elsif mark >= 70
    3
  elsif mark >= 60
    2
  else
    1
  end
end

Rubyでは最後に評価された式が戻り値になります。`else if` ではなく `elsif` です。

B4. Ruby構文の説明 15点

次のRuby構文・式の意味や使い方を簡単に説明しなさい。

  1. `(1..10)`
  2. `array.each do |item| ... end`
  3. `"mark is #{mark}"`
  4. `"80".to_i`
  5. `nil`
  6. `3.odd?`
  7. `@name`
  8. `puts` と `print` の違い
  1. 1から10まで、両端を含むRange。
  2. 配列の各要素に対してblockを実行する反復。
  3. ダブルクォート文字列内の式展開。`mark` の値を文字列に埋め込む。
  4. 文字列 `"80"` を整数 `80` に変換する。
  5. 値がないことを表すRubyのオブジェクト。
  6. メソッド名が `?` で終わる述語メソッド。奇数なら `true`。
  7. インスタンス変数。オブジェクトごとの状態を持つ。
  8. `puts` は最後に改行を付ける。`print` はそのまま出力する。

D5. 統計値を計算する 16点

wrestlers = Wrestler.all

if count == 0

  average_weight = 0

else

  4. フォームから `exponent` を受け取って表を作り直す。
  5. 不正な入力にデフォルト値を設定する。

  1. 表、行、列、主キー、外部キーの意味を説明する。

  4. 表名複数形とクラス名単数形の規約を説明する。

直前暗記

項目最低限の答え
HTMLの基本構造`<!doctype html>`, `html`, `head`, `title`, `body`。
構造と見た目の分離HTMLは構造/意味、CSSは見た目。再利用性、保守性、データ量、役割分担に利点。
CSS規則`selector { property: value; }`。
時計回り4値は上・右・下・左。3値は上・左右・下。2値は上下・左右。
Rubyの実行`irb` は対話確認、`ruby file.rb` はプログラム実行。
Rubyの型変換`to_i`, `to_f`, `to_s`。
Rangeとeach`(1..5).each do |n| ... end`。`..` は終端を含む。
CGIの先頭`Content-Type: text/html;charset=UTF-8` と空行。その後HTML。
ERBタグ`<% %>` 実行のみ、`<%= %>` 出力、`<%# %>` コメント。
query part`?exponent=0.7&step=5`。値は文字列なので変換する。
フォーム`form method="get"`, `label`, `input type="text"`, `input type="submit"`。
ORM対応表↔クラス、行↔オブジェクト、列↔属性/getter/setter。
規約表名は複数形、モデルクラス名は単数形。例: `wrestlers` ↔ `Wrestler`。
