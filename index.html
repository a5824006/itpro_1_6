過去問傾向

2019/2022/2023/2024/2025年の期末では、単語暗記だけでなく「分類して説明する」「コードを書く」「処理の流れを図や文章で説明する」問題が多いです。中間向けには次を重点化します。

  • コード分類 HTML/CSS/Ruby/Rails/コマンド/ファイル名を見分け、1文で説明する。
  • CSS shorthand、箱モデル、優先順位、継承を読めるようにする。
  • ERB `each` と `<%=` を使って表やリストを生成する。
  • Ruby `end` で閉じる構造、型変換、Range/Arrayの反復、CからRubyへの置換。
  • Q&A型 典型エラーの意味と、どこを見るかを答える。
  • HTTPからDB ブラウザ、クエリ、テンプレート、Active Record、データベースの流れを説明する。
  • HTML要素 2025年分ではリスト要素・ページ全体構造の要素が直接問われている。
期末過去問にはRails後半の内容も含まれます。第1-6回の中間では、Railsコマンドやmigrationの細部より、Active Recordとデータベースの考え方、Web入力から処理までの流れを優先します。

1. 用語の説明 18点

次の用語について、日本語訳または意味と、ITPro2での役割を1-2文で説明しなさい。

  1. HTML
  2. element
  3. attribute
  4. structural markup
  5. CSS rule
  6. selector
  7. box model
  8. Ruby block
  9. string interpolation
  10. CGI
  11. ERB
  12. query part
  13. form
  14. database
  15. primary key
  16. ORM
  17. Active Record
  18. convention over configuration
  1. HTML: Webページの構造と意味をマークアップする言語。
  2. element: `<p>...</p>` のように、開始タグ・内容・終了タグなどで表される構成単位。
  3. attribute: 開始タグ内で要素に追加情報を与えるもの。例: `id`, `class`, `lang`, `href`。
  4. structural markup: 見た目ではなく、段落・見出し・強調など文書上の役割を表すマークアップ。
  5. CSS rule: セレクタと宣言ブロックからなるスタイル指定。例: `p { color: navy; }`。
  6. selector: CSSを適用する対象を選ぶ部分。例: `p`, `.warning`, `#main`, `p code`。
  7. box model: 内容、padding、border、marginから要素の箱を考えるモデル。
  8. Ruby block: メソッド呼び出しに渡す処理のまとまり。`do ... end` や `{ ... }` で書く。
  9. string interpolation: ダブルクォート文字列中の `#{...}` で式の値を埋め込む機能。
  10. CGI: Webサーバが外部プログラムを呼び出し、標準出力からWebページを返す仕組み。
  11. ERB: HTMLの中にRubyコードを埋め込むテンプレート。`.html.erb` で使う。
  12. query part: URIの `?` より後ろ。`name=value&name2=value2` の形でパラメータを送る。
  13. form: ユーザ入力を送るHTML要素。`input`, `label`, `submit` などを含む。
  14. database: 多数のデータを構造化して保存・検索する仕組み。
  15. primary key: 表の各行を一意に識別する列。典型例は `id`。
  16. ORM: オブジェクト指向言語のオブジェクトと、リレーショナルDBの表・行を対応させる仕組み。
  17. Active Record: Railsで使われるORM。表の行をRubyオブジェクトとして扱える。
  18. convention over configuration: 規約に従えば細かい設定を書かずに動くというRailsの考え方。

2. HTML構造を書く 12点

「RubyとWebアプリ」という題名のWebページを作る。次の条件を満たすHTMLを書きなさい。

  • `lang` は日本語。
  • `head` には `meta charset` と `title` を入れる。
  • `body` には `header`, `nav`, `main`, `section`, `footer` を使う。
  • `nav` にはページ内リンクを2つ入れる。
  • 本文では `strong`, `em`, `code`, `abbr` を自然に使う。
<!doctype html>
<html lang="ja">
<head>
  <meta charset="utf-8">
  <title>RubyとWebアプリ</title>
</head>
<body>
  <header>
    <h1>RubyとWebアプリ</h1>
  </header>
  <nav>
    <ul>
      <li><a href="#ruby">Ruby</a></li>
      <li><a href="#web">Webアプリ</a></li>
    </ul>
  </nav>
  <main>
    <section id="ruby">
      <h2>Ruby</h2>
      <p><strong>Ruby</strong> では <code>each</code> をよく使う。</p>
    </section>
    <section id="web">
      <h2>Webアプリ</h2>
      <p><abbr title="Common Gateway Interface">CGI</abbr> は
      <em>動的</em>なページを作る方法の一つである。</p>
    </section>
  </main>
  <footer>
    <p>ITPro2 practice</p>
  </footer>
</body>
</html>

採点では、見た目を変えるために見出しを乱用していないか、入れ子が正しいか、属性値が引用符で囲まれているかも見られやすいです。

3. CSSを読む・書く 16点

次のCSSについて、各セレクタの種類と、指定される内容を説明しなさい。

main p code {
  background-color: #f6f6f6;
  padding: 0.1em 0.3em;
}

.warning {
  color: red;
  border: 2px solid orange;
}

#summary {
  margin: 1em 2em 3em 4em;
}

さらに、`#summary` の margin の上・右・下・左を答えなさい。

  • `main p code`: 子孫結合子。`main` の中の `p` の中にある `code` 要素に適用。背景色と内側余白を指定。
  • `.warning`: class selector。`class="warning"` を持つ要素に適用。文字色を赤、枠を2px solid orangeにする。
  • `#summary`: id selector。`id="summary"` の要素に適用。外側余白を指定。

時計回りなので、`margin: 1em 2em 3em 4em;` は上1em、右2em、下3em、左4em。

4. Rubyの構文 18点

次のC風の関数と同じ働きをするRubyのメソッドを書きなさい。0から100までの点数 `mark` と実数 `exponent` を受け取り、変換後の点数を整数で返す。

int convert_mark(int mark, double exponent)
{
    return round(pow(mark, exponent) * (100.0 / pow(100, exponent)));
}

その後、0, 10, 20, ..., 100 について、`n points -> converted points` の形で出力するRubyコードも書きなさい。

def convert_mark(mark, exponent)
  (mark**exponent * (100.0 / 100**exponent)).round
end

(0..100).step(10).each do |n|
  puts "#{n} points -> #{convert_mark(n, 0.5)} points"
end

`**` は累乗、`.round` は四捨五入、`#{...}` は文字列補完です。`(0..100)` は両端を含むRangeです。

6. Webフォームとクエリ 16点

`count` と `exponent` をGETで送るフォームを書きなさい。フォームの送信先は現在のページでよい。各入力欄にはlabelを付け、初期値はそれぞれ `10`, `0.5` とする。

また、サーバ側で `servlet_request.query` から値を取り出すときの注意点を3つ書きなさい。

<form method="get">
  <p>
    <label for="count">Count: </label>
    <input type="text" id="count" name="count" value="10">
  </p>
  <p>
    <label for="exponent">Exponent: </label>
    <input type="text" id="exponent" name="exponent" value="0.5">
  </p>
  <input type="submit" value="Calculate">
</form>
  1. 取り出した値は文字列なので、数値計算前に `.to_i` や `.to_f` で変換する。
  2. パラメータが存在しない場合は `nil`、値が空の場合は `""` になりうるので確認する。
  3. 文字や負の値など、使えない入力にはデフォルト値を使うなどの処理が必要。

A2. HTMLの表 6点

バージョンC: Q&Aフォーラム型

C1. エラーへの回答 15点

次の質問に対して、Q&Aフォーラムで返すならどう答えるかを書きなさい。

`syntax error, unexpected end-of-input, expecting keyword_end` の意味が分かりません。
`String can't be coerced into Integer` と出ます。
CGIで `Internal Server Error` になり、ページが表示されません。
フォームで入力した数値を計算に使うと変です。
ブラウザのエラーだけでは原因が分かりません。どこを見ますか。
`expecting keyword_end`
Rubyコードのどこかで `end` が足りない可能性が高い。`def`, `if`, `each do` などの開始と終了を対応させて確認する。
`String can't be coerced into Integer`
文字列と整数をそのまま計算している可能性がある。入力値を `.to_i` または `.to_f` で数値に変換する。
`Internal Server Error`
CGIなら最初に `Content-Type` ヘッダと空行を正しく出しているか確認する。Rubyの実行エラーも確認する。
フォーム入力が変
queryから来る値は文字列。`nil`, 空文字、文字入力、負数などをチェックし、必要ならデフォルト値を使う。
どこを見るか
Webサーバを起動したコマンドプロンプトの出力、サーバログ、ブラウザの開発者ツールを確認する。

バージョンD: HTTPからDBまで

D1. 処理の流れ 18点

ユーザがフォームに `min_weight=120` と入力し、送信した。サーバ側ではその値を使って、体重120kg以上の力士だけを表で表示する。この流れを、ブラウザ、URI/query、ERB、Active Record、データベースという言葉を使って説明しなさい。

  1. ブラウザはフォームの入力から、`?min_weight=120` のようなquery partを持つURIを作ってGETリクエストを送る。
  2. サーバ側テンプレートでは `servlet_request.query['min_weight']` のように値を取り出す。
  3. 値は文字列なので、`to_f` や `to_i` で数値へ変換し、空や不正値ならデフォルト値を使う。
  4. Active Recordで `Wrestler.where('weight >= ?', min_weight)` のようにデータベースへ条件付き問い合わせを行う。
  5. 返ってきた `Wrestler` オブジェクトの配列/集合をERBの `each` で回し、HTMLの表として出力する。
  6. 生成されたHTMLがブラウザへ返り、ユーザに結果が表示される。
